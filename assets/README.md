概念插图的生成提示词：

> Create an editorial educational illustration for a Chinese open source GitHub course called GEO 学习地图. Landscape canvas, crisp professional technical workbook style, warm off-white paper, dark navy linework, teal and small orange accents. A visual learning map, NOT a dashboard, no fake performance metrics, no logos. Across the upper half show three large distinct outlined places: a public website browser window, a phone with a mini program, and a standalone desktop/app product box. Each connects via clean branching dotted paths into a central open reference book with source citations represented by small numbered tags. From book a path leads to an AI answer speech bubble, then a magnifying glass examining a source, then a small experiment notebook. Sophisticated calm diagram illustration with generous margins and strong hierarchy. Only these short Chinese labels, accurately legible in clean modern sans-serif, no other text: main title 'GEO 学习地图'; smaller labels over the three places '网站', '小程序', '独立产品'; bottom three labels '公开证据', '准确引用', '复测验证'. Intent: a course map conveying that different product surfaces need accessible evidence and measured learning. Conceptual original illustration, never impersonate a real product screenshot. No 3D glossy shapes, no decorative AI brain, no robot, no glow, no charts.
