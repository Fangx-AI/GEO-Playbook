# 第 5 步 · 诊断：为什么 AI 不提你、说错你

**目的：** 从采样记录里找出病因，开出按优先级排好的处方。

## 先算四个数（写清分母）

先按**批次、平台、入口、问题集版本**筛选，使用该批次的事实卡快照和题目分类。有效回答为“完整”或“拒答”；无引用、未推荐、回答不知道仍留在分母。技术失败、不完整、未运行和未知单列，不按“没提到”计数。报告计划次数、有效回答数及各状态数量；分母为 0 写 `NA`。旧记录无法还原状态或批次时先标“未知”，不要直接混入新批次。

| 指标 | 怎么算 | 看什么 |
| --- | --- | --- |
| 提及率 | A 类有效回答中正文提到你的次数 ÷ A 类有效回答数 | 不带品牌时 AI 会不会想到你；提及不等于推荐 |
| 正确率（按回答） | B 类有效回答中“描述是否正确”为“对”的次数 ÷ B 类有效回答数 | 按预设判定标准检查价格、功能；部分错、错、未涉及、未知不算对，未知另报 |
| 排除正确率 | C 类有效回答中“排除是否正确”为“对”的次数 ÷ C 类有效回答数 | 满足预设排除标准；拒答和答非所问不算对 |
| 引用来源分布 | 有效回答的来源按“回答 × 原始 URL”去重后按域名或平台计数 | 只表示可见引用，不代表全部检索来源；仅有标题的来源另列待核实，不猜 URL |

上述正确率按整条回答统计，不等同于按断言统计的事实正确率。D 类逐题记录使用建议的错误，不混入 A/B/C 分母。引用来源未补齐时注明覆盖了多少条回答，分布只能视为暂定结果。

样本少的时候如实说："20 次里提到 3 次"，不要写成"提及率 15%，提升空间巨大"这种夸张结论。

## 再找病因

每道没提到你或说错你的题，归到下面一类：

病因是待验证假设。每条附原文、来源或体检证据，并区分“已观察到”和“待验证”；仅凭缺少品牌、引用第三方或旧页面，不能证明网站读不到、没覆盖或缺背书。

| 病因 | 怎么判断 | 处方方向 |
| --- | --- | --- |
| ① 读不到 | 体检发现抓取或内容读取障碍；仅引用旧页面或第三方不足以确认 | 先修有证据的体检问题（第 1 步） |
| ② 说法不一致 | 错误内容能在你自己的某个旧渠道找到（旧文章、应用商店、百科） | 改那个渠道，统一到事实卡（第 2 步） |
| ③ 没有覆盖 | 你的任何公开内容都没回答这个问题 | 针对这道题写内容（第 6 步） |
| ④ 不在它读的平台 | 你有内容，但在目标 AI 不常引用的平台上；AI 引用的是别的平台 | 把内容发到它常引用的平台（第 7 步） |
| ⑤ 缺第三方背书 | AI 推荐的同行都有媒体报道、测评、知乎回答等第三方内容，你只有自家官网 | 争取真实的第三方测评和报道（第 7 步），**不能自己编** |
| ⑥ 本来就不适合 | 是 C 类题，或需求确实超出你的能力 | 不用治，这是正确结果 |

**看同行赢在哪：** 对没提到你的 A 类题，记下 AI 推荐了谁、引用了哪几个来源。打开这些来源看：是什么平台、什么形式（对比文章、清单、问答、测评）、哪一段被引用。这就是你要补的内容形式和平台。

## 写处方

写进 `geo/diagnosis.md`，按优先级排：

1. **先治错**：AI 说错的价格、功能、限制。这类问题伤害最大，修起来也最快。
2. **再治读不到**：体检里的致命问题。
3. **再补覆盖**：价值最高的 A 类题，挑同行在你能发布的平台上赢你的那几道。
4. **最后补背书**：第三方内容需要时间，列出目标，但不要指望很快见效。

每条处方写清：哪道题 → 病因 → 做什么 → 在哪个平台做 → 第几步执行。处方一次不超过 5 条，太多用户做不完。

## 完成标准

- `geo/diagnosis.md` 有四个数（带分母）、病因归类、同行分析、不超过 5 条处方
- 告诉用户最重要的 1 到 2 个发现，以及"接下来我帮你写第 1 条处方要的内容"
