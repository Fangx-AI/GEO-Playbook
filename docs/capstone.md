# 🎓 毕业项目：完成一轮可复查的 GEO

> [GEO 学习地图](../README.md) › 毕业项目

**选一个你有权限修改的真实页面，按 8 步走完一轮。做完你就有一份能给老板、客户或面试官看的完整 GEO 作品。**

没有网站也能做：先完成问题研究、现状审查和离线改稿，结果标为“未发布、未验证”。

| 步骤 | 具体怎么做 | 留下的材料 | 参考 |
| --- | --- | --- | --- |
| 1. 明确目标 | 写出用户、使用情境和要做的决定 | 一句话目标与适用范围 | [入门](basics.md) |
| 2. 收集问题 | 从客服、销售、访谈整理真实问题；品牌题和非品牌题分开 | 有编号的题集与来源 | [提示词 P1](../toolkit/prompts.md) |
| 3. 记录基线 | 在选定平台按相同条件重复观察；没出现品牌的样本也保存 | 原始记录、条件、当前指标 | [测量课](measurement.md) |
| 4. 找一个缺口 | 判断是事实缺失、表达不清、技术障碍，还是暂时无法判断 | 证据、改动假设、替代解释 | [网站诊断](playbooks/website.md) |
| 5. 做有限修改 | 第一轮只改一类东西；保存改前改后版本 | 改稿单、差异、审核记录 | [改稿课](content-rewrite.md) |
| 6. 发布并记录 | 写清实际时间和地址，记录可见的抓取或索引证据 | 发布日志 | [检查清单](../toolkit/checklists.md) |
| 7. 按原口径复测 | 相同题集和条件；有条件就保留未改的对照页 | 前后及对照的绝对计数 | [案例：Webflow](cases.md#webflow) |
| 8. 复盘 | 写清改善、下降、无变化、未知分别是什么，决定继续、回滚或换假设 | 一页结论 + 下一轮计划 | [研究速读](studies.md) |

**合格的提交**：问题与事实表、改前改后内容、实拍图与来源、发布差异、完整观察记录、可重算的结论。没有增长也可以毕业，诚实记录本身就是能力。

**不合格的提交**：只写“优化了权威性”；只留表现最好的一次回答；只有百分比没有计数；把概念图当实测截图；把模拟数据写成客户成绩。

> 🙌 做完了？欢迎用 [Issue](https://github.com/Fangx-AI/geo-learning-map/issues/new/choose) 分享你的项目（可以脱敏），优秀作品会收录进案例库。
