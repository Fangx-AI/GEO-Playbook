# ✅ GEO 检查清单

> [GEO 实战手册](../README.md) › 工具箱 › 检查清单

**三张清单，打印出来贴在工位上：上线前查一遍，发布前查一遍，每周复盘查一遍。**

- [清单 1 · 15 分钟 GEO 体检](#audit)：AI 能不能读到你、说得对不对
- [清单 2 · 发布前审核](#prepublish)：这一页能不能上线
- [清单 3 · 每周观察](#weekly)：效果怎么记才不自欺

<a id="audit"></a>

## 清单 1 · 15 分钟 GEO 体检

挑一个最重要的业务页面（产品页、价格页、门店页），逐项打勾。

**能读到吗**（可用 [`geo-audit.sh`](geo-audit.sh) 或 Windows 版 [`geo-audit.ps1`](geo-audit.ps1) 自动检查前 5 项）

- [ ] 页面返回 200，且保存下来的 HTML 是正文，不是登录框、验证码或“页面不存在”
- [ ] 跳转不超过 1 次，站内链接直接指向最终地址
- [ ] `robots.txt` 没有误封 `Googlebot`、`bingbot`、`OAI-SearchBot`、`PerplexityBot`、`Claude-SearchBot`
- [ ] HTML 的 robots meta 和响应头 `X-Robots-Tag` 都没有误加 `noindex`
- [ ] `canonical` 指向本页，不是首页或别的页面
- [ ] 关键正文（价格、条件、限制）在**原始 HTML** 里，不依赖 JavaScript 才出现
- [ ] CDN / WAF 没有拦截搜索类爬虫（查防火墙日志，不只看 robots）
- [ ] 从首页或分类页有普通 `<a href>` 链接能点到这一页

**说得对吗**

- [ ] 第一屏就能看出：这是什么、给谁用、**不适合谁**
- [ ] 价格写清计费单位、包含什么、额外收费；举一个算式
- [ ] 每个能力旁边紧跟它的限制条件
- [ ] 官网、帮助文档、商店、地图、公众号上的同一事实说法一致
- [ ] 页面上有更新日期，旧版本信息已下线或明确标注

**AI 现在怎么说你**

- [ ] 在 2 个目标 AI 上，用 3 个**不含品牌名**的真实问题各问一次，保存回答和引用
- [ ] 再问 2 个品牌事实题（价格、限制），对照事实卡判断对错

<a id="prepublish"></a>

## 清单 2 · 发布前审核

- [ ] 每一句事实都能对应到事实卡的一个编号（可用 [提示词 P5](prompts.md#p5) 辅助）
- [ ] 没有“领先、最佳、全面、所有、100%、无损”等无法核实的词
- [ ] 价格和数字已用计算器重算
- [ ] 能力和限制在同一句或相邻句，单独复制任何一句都不会误导
- [ ] “未知”和“待确认”的事项没有被写成承诺
- [ ] 截图、实拍图来自当前版本，图注写明时间；关键信息在正文里也有文字版
- [ ] 请一位没参与写作的人用 3–6 个真实问题测试：都能在正文里找到答案
- [ ] 保存改前副本、改后副本、发布时间和 URL，便于之后复盘
- [ ] 只更新真正修改过的页面的 sitemap `lastmod`

## 清单 3 · 每周观察

- [ ] 题集、平台、入口、地区、语言、是否登录、是否联网，和基线完全一致
- [ ] 每道题开新会话，不在同一会话里反复追问
- [ ] 每题至少重复 2–3 次，保存**所有**结果，不挑最好的截图
- [ ] 请求失败记为 `technical_error`，不记为“没提到”；拒答、没推荐照样计入
- [ ] 提及、引用、引用是否准确、可识别访问、业务成交，分五列记录
- [ ] 打开每条引用，确认它真的支持旁边那句话
- [ ] 同期的其他变化（改版、投放、活动、平台更新）写进备注
- [ ] 结论写绝对计数和分母，区分百分点和百分比
- [ ] 没变化、变差的题也写进周报
